# Student Project Uploads

Upload student project images and exported poster PDFs in this folder.

Supported file types: `.png`, `.jpg`, `.jpeg`, `.avif`, `.webp`, `.gif`, and `.pdf`.

Files in this folder appear automatically in the Student Projects section. Use short, descriptive filenames, such as `flood-alert-app.png` or `flood-alert-poster.pdf`.

Project cards are created from these uploads automatically. Add an entry to `/src/data/showcaseContent.ts` only when you want to replace the default title, category, description, or student details.
